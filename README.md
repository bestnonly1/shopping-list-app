# 🛒 쇼핑리스트 앱

빌드나 설치 없이 `index.html` 파일 하나로 동작하는 쇼핑 리스트 웹 앱입니다.

## 기능

- 항목 추가 (Enter 또는 "추가" 버튼, 앞뒤 공백 제거, 빈 입력 무시, 최대 100자)
- 체크해서 구매 완료 표시 / 해제
- `×` 버튼으로 항목 삭제
- "완료한 항목 지우기"로 체크한 항목 한 번에 삭제
- "전체 n개 · 남은 것 n개" 요약 표시
- 브라우저 `localStorage`에 자동 저장 (새로고침해도 유지)

## 실행 방법

`index.html`을 브라우저로 열면 바로 사용할 수 있습니다.

## 기술

- HTML / CSS / 바닐라 JavaScript (프레임워크 없음)
- 사용자 입력은 `textContent`로만 화면에 넣어 XSS를 막습니다.
